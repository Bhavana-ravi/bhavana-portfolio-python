# Bhavana Ravi Kumar — Portfolio

A responsive, dependency-free portfolio website. Open `index.html` in a browser to preview it locally.

## Deploy with GitHub Pages

1. Create a new GitHub repository, e.g. `bhavana-portfolio`.
2. Upload the contents of this folder (not the folder itself) to the repository root and commit.
3. On GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. In a minute or two, your public site URL will appear on that page. Add it to your LinkedIn and resume.

## Deploy with Netlify (fastest)

1. Go to [Netlify Drop](https://app.netlify.com/drop).
2. Drag this entire `portfolio` folder onto the page.
3. Netlify publishes it immediately and lets you customize the web address.

## Before publishing

- Replace or add project links in `index.html` if you have public repositories for the projects.
- To connect the project cards, replace `REPLACE-COURIER-REPO` and `REPLACE-BANK-REPO` in `index.html` with the respective GitHub repository names. For example: `https://github.com/Bhavana-ravi/courier-service-system`.
- Add a professional photo later if desired; this design intentionally works without one.
- The email, GitHub, and LinkedIn links are already populated from the resume.
